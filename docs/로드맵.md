## 1. 운영 원칙

1. 각 레이어는 이전 레이어가 작동한다는 전제 위에 기능을 얹는다. 단순 기능 추가가 아닌 점진적 고도화로 구성한다.
2. 시험 휴회 기간(6/16–6/22)에는 신규 기능 도입을 금지하고 폴리시·평가·문서 작업에 한정한다.
3. 페르소나 1종(개발자)으로 시작하여 Layer 3에서 마케터·기획자로 확장한다.
4. 크롤링 소스는 6종으로 구성한다 — 자동 수집 4종(Reddit, GitHub Trending, Hacker News, Velog/Tistory RSS)과 일회성 Apify 스크레이퍼 2종(X, Threads).
5. 자가복제 메커니즘은 1회 루프 시연으로 정의한다. Auto-HKG에 의한 그래프 노드 자동 생성이 핵심 시연 포인트이다.
6. 모든 데모는 팀 내부 대상이다. 외부 검수자나 지도교수는 포함하지 않는다.

## 8. 최종 발표 (6/29 월)

3차 데모와 동일한 범위로 진행한다.

### 발표 메시지

> 본 플랫폼은 AI 시대의 학습 플랫폼이다. 따라서 추천 자체도 정적 모델이 아니라 LLM 에이전트가 "이 콘텐츠를 다음에 학습해야 하는 이유"를 설명하는 방식으로 동작한다.
>
> 자가복제 1회 루프 시연을 통해, 시스템 구조상 유저가 늘어남에 따라 그래프가 스스로 진화함을 확인할 수 있다. 이는 *Agentic Deep Graph Reasoning Yields Self-Organizing Knowledge Networks* (arXiv:2502.13025)의 핵심 아이디어와 일치한다.
>
> Layer 3에서 보인 페르소나 확장은 동일한 시스템이 도메인 경계를 넘어 일반화 가능함을 입증한다.

### Future Work

- 유저 상호작용 데이터 누적 시 GraphSAGE 임베딩의 supervised fine-tuning (collaborative signal 본격 도입)
- X API Basic 구독 또는 X/Threads 자동 파이프라인 확장
- Generative Recommendation (TIGER, Semantic IDs) 으로의 확장
- LLM 태깅을 KoBERT 등 소형 모델로 distillation하여 추론 비용 절감
- 추가 페르소나 (디자이너, 데이터 분석가 등)
