# 자가복제형 기술 커뮤니티 — 시스템 파이프라인 v4 (Layer 2 완료 반영)

**설계 원칙:** 비용 효율성, 2025–2026년 최신 연구 동향(SOTA) 부합, 자가복제 컨셉과의 정합성, 학술적 산출물(학습 컴포넌트) 확보 — 네 축의 교집합에 위치하도록 설계
**멀티소스 구성:** 6종 (Velog/Tistory, Reddit, GitHub Trending, HuggingFace, X — Hacker News·Threads 폐기)
**학습 컴포넌트:** GraphSAGE 자기지도학습으로 멀티소스 콘텐츠 그래프 노드 임베딩 산출
**MVP 총 비용:** 미화 35달러 이내

**현행 파이프라인 (전 단계 구현·운영 중, 2026-06-11):**

```
크롤 (velog/tistory · reddit · github_trending · huggingface · x)
  → QC 게이트 (backend/app/crawler/qc_gate.py — LLM 비용 전 휴리스틱)
  → 가공 synthesis (content_type 5종 카드, 태깅 후 적재 시 또는 추천 확정 시 lazy)
  → 태깅 (Claude Haiku, Message Batches)
  → 임베딩 (OpenAI text-embedding-3-small, 1536d, 원문 고정)
  → Auto-HKG v2 (2패스: 흡수 0.70 → 클러스터링 0.65/MIN 3 → LLM 네이밍)
  → GraphSAGE (export → 로컬 학습 → graph_embedding 256d 적재)
```

평가 실측(통합본 994건): modularity 0.512 / tag_purity_topic 0.7745(baseline 0.4143) /
V-measure_topic 0.4238(baseline 0.1481) / coverage 0.214 / orphan 0 / e2e 연결점검 11/12.

## 1. 핵심 명제

> LLM이 6개의 서로 다른 커뮤니티/플랫폼에서 수집한 글을 그래프에 자동으로 편입시키고, 그래프 자체가 자기조직화(self-organizing) 양상으로 진화하며, GraphSAGE로 학습된 노드 임베딩이 추천에 활용된다. 추천은 GraphRAG 패턴을 통해 추천 근거까지 자연어로 생성한다.

학술적 근거: [Agentic Deep Graph Reasoning Yields Self-Organizing Knowledge Networks (arXiv:2502.13025)](https://arxiv.org/abs/2502.13025)

### 3.2 Auto-HKG — 자기조직화 그래프

**관련 연구:** [Generative GraphRAG / Auto-HKG (MDPI 2025)](https://www.mdpi.com/2076-3417/15/14/7655), [Beyond Static Question Banks (arXiv:2602.00020)](https://arxiv.org/pdf/2602.00020)

**입력:** 멀티소스 크롤링 콘텐츠 및 유저 업로드 글
**출력:** 그래프에 노드 및 엣지 자동 편입

```
[새 콘텐츠 (6개 소스 중 하나)]
   ↓
Haiku 태깅 (토픽 / 난이도 / 직군 / 퀄리티 점수 / 언어)
   ↓
text-embedding-3-small로 임베딩 생성 (1536차원)
   ↓
LLM 그래프 적합도 판단:
   - 기존 CurriculumNode에 매칭 가능 → belongs_to 엣지 생성
   - 매칭 불가 → 새 하위 노드 자동 생성 (Auto-HKG)
   ↓
pgvector 기반 유사도 상위 5건 → similar_to 엣지 생성
   ↓
그래프 진화 — 즉시 모든 추천 결과에 반영
```

**멀티소스 효과:** 서로 다른 출처의 글이 같은 CurriculumNode 또는 같은 Tag로 묶이는 양상이 그래프 시각화에서 시각적으로 강조된다.

### 3.3 GraphSAGE 자기지도학습 — 그래프 표현 학습

**관련 연구:** GraphSAGE 원논문(Hamilton et al., NeurIPS 2017), 본 프로젝트의 자가복제 명제와의 연결([arXiv:2502.13025](https://arxiv.org/abs/2502.13025))

**입력:** Content–Author–Tag–CurriculumNode 이종 그래프 (멀티소스 데이터 기반)
**출력:** 각 노드의 임베딩 벡터 (학습 산출물)

```
[그래프 구축]
   - 노드: Content, Author(작성자), Tag, CurriculumNode, Source(출처)
   - 엣지: authored, tagged_as, belongs_to, similar_to,
          posted_in (콘텐츠와 출처 연결),
          co-engaged (같은 유저가 상호작용한 콘텐츠 쌍)
   ↓
[학습 목표 — 자기지도, 라벨 불필요]
   - Link prediction: 임의의 엣지를 가린 뒤 복원
   - Contrastive loss: 같은 토픽 노드끼리 가깝게,
                       다른 토픽 노드끼리 멀게
   ↓
[학습 환경]
   - Google Colab 무료 티어 (T4 GPU)
   - PyTorch Geometric
   - 시드 약 2200개 노드 규모면 무료 티어로 충분
   ↓
[산출물]
   - 노드 임베딩 (1536차원 → 256차원 압축)
   - 학습 곡선, 평가 지표 (link prediction AUC)
   ↓
[추론 단계 통합]
   - GraphSAGE는 inductive 특성 → 신규 노드도
     이웃 기반으로 임베딩 산출 가능
   - 텍스트 임베딩과 결합하여 추천 retrieval에 활용
```

**텍스트 임베딩과의 결합**
- 텍스트 임베딩: 콘텐츠 의미적 유사도 (cold start 강점)
- GraphSAGE 임베딩: 그래프 구조적 유사도 (collaborative signal 및 출처 다양성 신호)
- Retrieval Stage A에서 가중 평균(0.5/0.5 시작) 후 코사인 유사도 계산

### 3.4 LLM Knowledge Tracing — 유저 mastery 트래킹

**관련 연구:** [Next Token Knowledge Tracing (arXiv:2511.02599)](https://arxiv.org/abs/2511.02599), [LLM-KT (arXiv:2502.02945)](https://arxiv.org/html/2502.02945v1), [LPReKL (MDPI 2025)](https://www.mdpi.com/2079-9292/14/22/4385)

**입력:** 유저 읽음 이력, 자가평가 답변, 시간 정보
**출력:** 자연어로 표현된 mastery 상태 텍스트

```
유저가 콘텐츠 읽음/체크 → 시퀀스에 추가
   ↓
user_state 텍스트 직렬화:
   "- 노드 1(프롬프트 기초): 입문 2건 완료, 중급 1건 완료
    - 노드 2(자동화): 입문 1건 시작, 미완료
    - 출처 선호: Reddit·GitHub 콘텐츠 다수 읽음
    - 자가평가: 'Codex 기본 사용 가능, 하네스 미경험'"
   ↓
추천 단계 프롬프트 컨텍스트로 주입
```

### 3.5 GraphRAG Recommendation — 추천 및 근거 통합 생성

**관련 연구:** [Cold-Start RAG (arXiv:2505.20773)](https://arxiv.org/html/2505.20773v2), [LLM-KG Completion for Curriculum (arXiv:2501.12300)](https://arxiv.org/pdf/2501.12300), [Educational Learning Path Planning (arXiv:2407.11773)](https://arxiv.org/pdf/2407.11773)

```
유저 추천 요청
   ↓
Stage A: Retrieval (비용 무료)
   - 유저의 현재 노드 및 1-hop 이웃 노드에 속한 콘텐츠 추출
   - pgvector 기반 결합 임베딩(텍스트 + GraphSAGE)
     × user_vector 코사인 유사도 상위 10건
   - 룰 필터 적용: 미독 여부 / 난이도 ≤ 유저 단계 + 1
   - 다양성 보장: 가능하면 후보 10건 중 최소 3개 이상의 서로 다른 출처 포함
   ↓
Stage B: Reasoning (Haiku 1회 호출)
   컨텍스트:
   - LLM KT가 생성한 user_state 텍스트
   - 후보 콘텐츠 10건의 제목, 태그, 요약, 출처
   - 그래프 이웃 정보
   요청 사항:
   - 다음 콘텐츠 상위 3건 선정 및 순서 결정
   - 1순위에 대한 자연어 근거 생성
   ↓
Stage C: 세션 캐시
```

비용: Stage A는 벡터 검색만 사용하므로 무료. Stage B는 Haiku 1회 호출로 약 미화 0.0005달러.

## 7. 데모 시나리오

데모 일정은 4회로 구성된다. 모든 데모는 팀 내부 대상이다.

**1차 데모 (5/31): Walking Skeleton**
1. Reddit 단일 소스 기반 시드 100–200건 표시
2. 룰베이스 추천 결과 노출
3. 데이터 흐름이 end-to-end로 작동함을 확인

**2차 데모 (6/6): Core MVP**
1. 데모 프로필로 로그인 (개발자 페르소나)
2. 6개 소스가 혼합된 첫 커리큘럼 추천 5건 (출처 뱃지)
3. 콘텐츠 2건 읽음 처리 → 다음 추천 즉시 변경
4. 추천 근거 자연어 설명 확인
5. GraphSAGE 학습 곡선 및 t-SNE 임베딩 시각화 (슬라이드)

**3차 데모 (6/28): Expansion 완성판 (= 최종 리허설)**
