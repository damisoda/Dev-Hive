# 자가복제형 기술 커뮤니티 (Self-Evolving Dev Community)

> **커뮤니티의 경험이 곧 다른 사람의 학습이 되는 플랫폼**  
> AI 트렌드처럼 빠르게 변하는 도메인에서, 커뮤니티 자체가 살아있는 교과서가 된다.

---

## 문제 의식

AI의 발전 속도가 너무 빠르다. 개인이 혼자 이 흐름을 따라가기엔 벅차다.

- Claude Code의 새 기능, 매일 올라오는 AI 패치노트
- GPT 이미지 생성, Crew AI의 멀티 에이전트 피드백 루프
- Obsidian × Claude 연동, GitHub 플러그인 생태계
- ...그리고 이 모든 것이 6개월이면 낡아버린다

**그런데 기존 플랫폼은 이 속도를 따라가지 못한다.**

| 서비스 | 한계 |
|---|---|
| 인프런 / Udemy | 강의 하나당 유료, 6개월이면 낡은 콘텐츠 |
| Reddit / X | 정보는 넘치지만 구조화 없음 — 북마크하고 끝 |
| Dev.to / Hashnode | 글 공유는 되지만 개인화된 커리큘럼 불가 |

> "생산자가 멈추면 함께 멈추는 플랫폼이 아니라,  
> 유저가 경험을 올릴수록 스스로 진화하는 플랫폼이 필요하다."

---

## 솔루션: 자가복제형 교육 플랫폼

주니어 개발자들이 AI 툴을 써보고 공유하면, AI가 그 경험을 학습 콘텐츠로 변환해 커리큘럼에 자동 삽입한다.

```
유저 경험 업로드
    ↓
AI 처리 (토픽 분류 + 난이도 태깅 + 커리큘럼 매핑)
    ↓
비슷한 학습 단계의 유저 피드에 자동 삽입
    ↓
피드백 루프 (가중치 조절 + 작성자 영향력 점수 부여)
    ↓
커리큘럼 자동 확장 & 최신화
```

**콘텐츠 생산자가 멈춰도 커뮤니티는 계속 살아 움직인다.**

---

## 타겟 페르소나

> AI 툴에 관심은 있는데, 뭘 어떻게 배워야 할지 몰라서  
> Reddit이나 X만 구경하다 끝나는 비전공 or 주니어 개발자

구체적으로:

- 부트캠프 수료 후 취업 준비 중인 개발자
- 사이드 프로젝트에 AI 툴을 써보고 싶지만 진입점을 모르는 사람
- 정보는 넘치는데 "내 수준에 맞는 것"이 어딘지 모르는 사람

---

## 핵심 메커니즘

### 1. Input — 유저가 경험을 업로드
- "이거 써봤어" 형식의 자유로운 글 작성
- GitHub 확장 설정, 프롬프트 공유, 툴 후기 등

### 2. AI 처리 파이프라인
- **토픽 분류**: 어떤 기술/툴에 관한 글인지 자동 태깅
- **난이도 태깅**: 초급 / 중급 / 고급 자동 분류
- **커리큘럼 매핑**: 기존 학습 로드맵의 어느 위치에 해당하는지 연결

### 3. 개인화 피드
- 유저의 학습 단계에 맞는 콘텐츠만 노출
- "이걸 알면 다음엔 이걸" 흐름으로 자연스러운 커리큘럼 형성

### 4. 피드백 루프
- 글의 조회, 적용, 공유 데이터로 가중치 자동 조정
- 기여자에게 **영향력 점수** 제공 → 더 많은 공유 동기 부여

---

## 실제로 이미 일어나고 있는 신호들

커뮤니티 기반 기술 학습의 폭발적 성장이 이미 관찰되고 있다.

- Reddit r/claude, r/ChatGPT — 실사용 팁 쓰레드 수십만 조회
- X / Threads — AI 개발자 계정들의 팔로워 급성장
- 하지만 이 커뮤니티들은 **두 가지로 양극화**되고 있다:

| 유형 | 특징 | 결과 |
|---|---|---|
| 고밀도 커뮤니티 | 실제로 쓰고, 만들고, 공유하는 사람들 | 격차를 빠르게 좁힘 |
| 소비형 커뮤니티 | 정보는 많이 보는데 적용은 못 함 | 불안감 증폭, 적용 불가 |

> 이 플랫폼은 **소비형 유저를 고밀도 기여자로 전환**하는 것을 목표로 한다.

## 로드맵 (예정)

- [ ] **Phase 1 — MVP**: 글 업로드 + AI 토픽/난이도 태깅 + 기본 피드
- [ ] **Phase 2 — 커리큘럼**: 학습 단계별 개인화 피드 + 로드맵 시각화
- [ ] **Phase 3 — 피드백 루프**: 영향력 점수 시스템 + 콘텐츠 가중치 자동 조정
- [ ] **Phase 4 — 생태계**: 외부 플랫폼(GitHub, X 등) 연동 크롤링

## 기여하기

4. PR 생성
